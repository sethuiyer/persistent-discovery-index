# ENGINE_PORT.md — Rust→WASM engine + TypeScript UI (PROPOSAL, NOT FROZEN)

> Strategy/engineering proposal. **Not frozen.** No Rust code exists yet.

## 1. Target stack

| piece | stack |
|---|---|
| mathematical engine + trace parsing | **Rust** |
| browser bindings | `wasm-bindgen` + `wasm-pack` |
| UI | React + Vite + TypeScript |
| charts | Recharts |
| analysis execution | **Web Worker running WASM** |
| local persistence | IndexedDB |
| hosting | static site |
| experiment runner | native Rust CLI (orchestrates `pi` + verifiers) |

Drop a trace → WASM parses and profiles → UI shows diagnoses. **Traces stay in the
browser; no backend for profiling.**

**Tooling present:** `cargo` 1.98.1, `rustc` 1.98.1, `node` v22, `npm` 10.
**Missing:** `wasm32-unknown-unknown` target, `wasm-pack`.

## 2. The boundary — do NOT port the frozen ruler

`o4b_stat.py` is the **frozen decision statistic** for pilot 2, and its 10 000
resamples come from a specific Python MT19937 stream (`random.Random(seed).randrange`).
A Rust port with a different RNG yields **different decisions from the frozen rule**.

**Therefore:**
- **Rust/WASM is the descriptive instrument** — parse → tower → cost variance →
  per-parent energies → exposure → cards.
- **The ruler and the experiment runner stay Python** until pilot 2 has run. A native
  CLI may orchestrate `pi` and verifiers, but it **calls** the frozen Python ruler; it
  does not reimplement it.
- Porting the ruler happens **after** the pilot, with an exact MT19937 + `randrange`
  reimplementation and a differential test against Python.

## 3. Three constraints

1. **Exactness.** The audits assert exact rationals (`E_0 == 4/3`; currency scaling
   `k²`). Use `num-rational::BigRational` in the core and `f64` only at the JSON/UI
   boundary. Losing exactness silently deletes the property tests' meaning.
2. **Parity = differential tests.** Python is the **oracle**. Golden fixtures
   (`canonical trace + costs/tasks/levels → expected report`) plus a test that Rust
   matches. Two implementations without differential tests are two truths, which is
   what `test_repo_consistency.py` exists to prevent.
3. **Scope.** Port the *product path* only: parse → tower → cost variance (known
   cohort) → per-parent energies → exposure. **Not** transport / zeta / monodromy /
   prime-holonomy — research modules that never touch the UI. Parsers: **canonical +
   pi** first, not all eleven.

## 4. Layout

```
engine/                cargo workspace
  pdi-core/            trace model, partitioning tower, cost variance, exposure
  pdi-wasm/            wasm-bindgen surface (canonical JSON in -> report JSON out)
  pdi-cli/             native: orchestrate pi + verifiers; calls the Python ruler
ui/                    React + Vite + TS, Recharts, Web Worker + IndexedDB
fixtures/golden/       IR + expected reports, shared by Python and Rust
```

`.gitignore` additions: `engine/target/`, `ui/node_modules/`, `ui/dist/`,
`engine/Cargo.lock` decision to be made (binary → commit; library-only → optional).

## 5. Phases and acceptance

| phase | deliverable | acceptance |
|---|---|---|
| 0 | this contract + golden fixtures from the Python suite | fixtures regenerated by a committed script |
| 1 | `pdi-core`: canonical/pi parse, tower, `variance_shares` (known cohort, distinct-task support, unknown exclusion) | differential test vs Python passes on every fixture |
| 2 | per-parent cost energies, success energies, cost–success inner product; exposure (repetition + attributable spend, labelled an estimate) | parity + the same synthetic audits ported |
| 3 | `pdi-wasm` + minimal UI (drop a file → report + cards) | browser run reproduces a fixture |
| 4 | `pdi-cli` orchestration; export a card to GEPA | one end-to-end card from real traces |
| 5 | (post-pilot) port the ruler with exact RNG | frozen-rule numbers match Python exactly |

## 6. Non-negotiables carried over

- **Cost variation ≠ waste ≈ saving ≈ cause.** Exposure is a candidate for
  investigation, not proof of redundancy.
- **Unknown is a category, never a behavioural class**; selection runs on the
  **known cohort**.
- **No claim without the input warrant.** The refusal semantics must survive the
  port, not just the arithmetic.
